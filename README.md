# Акушерство-гинекология КРС

Полевой журнал для исследования: отёл, заболевания, качество уыза (Brix, «Лактан 1-4М»),
гематология/биохимия, передача иммунитета телятам.

## Как запустить на GitHub Pages (один раз)

1. Зайдите на https://github.com и создайте новый репозиторий (кнопка **New repository**).
   Имя любое, например `akusherstvo-krs`. Сделайте его **Public**.
2. На странице репозитория нажмите **Add file → Upload files** и загрузите файл
   `index.html` из этой папки (просто перетащите его).
3. Нажмите **Commit changes**.
4. Зайдите в **Settings → Pages** (слева в меню репозитория).
5. В разделе **Build and deployment → Source** выберите **Deploy from a branch**,
   ветка **main**, папка **/ (root)** → **Save**.
6. Через 1–2 минуты вверху появится адрес вида
   `https://ВАШ-ЛОГИН.github.io/akusherstvo-krs/` — это и есть постоянная ссылка
   на приложение. Откройте её на телефоне и добавьте на экран «Домой».

## Важно про данные

Это полностью автономная версия — без Google, без Claude, без какого-либо сервера.
Данные хранятся прямо в браузере устройства (localStorage) и **не синхронизируются**
между разными телефонами/компьютерами. Если очистить данные сайта в браузере —
данные будут потеряны. Если позже понадобится синхронизация между устройствами —
можно добавить бесплатный бэкенд (например, через Google Таблицу) отдельным шагом.
